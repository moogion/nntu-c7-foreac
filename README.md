# Лабораторные работы по курсу «Основы радиоэлектроники и связи»

Кафедра КТПП ИРИТ НГТУ им. Р.Е. Алексеева, направление 11.03.03 «Конструирование и технология электронных средств».

Отчеты подготовлены в [Typst](https://typst.app) с использованием шаблона `nntu-typst` (ГОСТ). Расчеты и моделирование реализованы на Python с управлением окружением через [Pixi](https://pixi.sh).

---

## Настройка окружения

1. **Клонирование репозитория с подмодулями:**
   ```bash
   git clone --recurse-submodules <url>
   # или для уже склонированного:
   git submodule update --init --recursive
   ```

2. **Установка зависимостей Python:**
   ```bash
   pixi install
   ```

---

## Запуск расчетов

Запуск осуществляется через задачи `pixi run`:

```bash
# Лабораторная работа 2 (Энтропия и сжатие)
pixi run lab2         # все задания (task1, task2, task3)
pixi run lab2-task1   # равновероятный источник и шифр Цезаря
pixi run lab2-task2   # анализ английского текста
pixi run lab2-task3   # анализ русского текста

# Лабораторная работа 3 (Сжатие Move-to-Front)
pixi run lab3

# Лабораторная работа 4 (Помехоустойчивое кодирование)
pixi run lab4         # все задания
pixi run lab4-task1   # бит четности и ARQ
pixi run lab4-task2   # код Хэмминга (7, 4)
pixi run lab4-task3   # серийный эксперимент и графики
```

## Структура работ

### ЛР 2. Исследование энтропии, избыточности и сжатия данных (`2_analysis-of-entropy`)
- `task1.py`: моделирование равновероятного источника, шифрование Цезарем, проверка инвариантности энтропии.
- `task2.py`: статистический анализ английского текста («Война и мир»), энтропия и избыточность.
- `task3.py`: анализ русского текста, оценка избыточности и степени сжатия Deflate.

### ЛР 3. Алгоритм сжатия Move-to-Front и префиксное кодирование (`3_mtf-compression`)
- `mtf.py`: преобразование текста алгоритмом MTF («стопка книг»), унарное префиксное кодирование и оценка степени сжатия.

### ЛР 4. Исследование методов помехоустойчивого кодирования в ДСК (`4_error-control-coding`)
- `task1.py`: побайтовая передача с проверкой на четность и запросом повтора (ARQ).
- `task2.py`: блочный код Хэмминга $(7, 4)$ с исправлением одиночных ошибок.
- `task3.py`: векторизованное моделирование в диапазоне ошибок $p \in [0; 0{,}45]$, сопоставление трафика и вероятности необнаруженных ошибок.
